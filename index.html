시스템 설계

Unity 엔진으로 만든 툴과 시스템으로 완성한 시뮬레이션

SceneView — AI Navigation

현실적인 AI 이동

도시 환경 곳곳에 배치된 NPC와 자연스럽게 돌아다닙니다.

Inspector — BlindnessSimulator.cs

커스텀 시야 시뮬레이션 셰이더

Fog Density, Bloom, Saturation 등 파라미터를 조절해 5가지 시각 손상의 증상을 현실적으로 재현합니다.

Tool — Tile Path Editor

자체 제작 타일 경로 에디터

점자블록과 이동 경로를 손쉽게 배치할 수 있는 자체 제작 Unity 에디터 확장 툴을 개발했습니다.

Character — White Cane Interaction

흰 지팡이 촉각 인터랙션

지팡이 끝이 점자블록과 장애물에 닿을 때 진동과 사운드로 피드백을 주는 인터랙션 시스템을 구현했습니다.
